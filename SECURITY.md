# Security Policy

## Reporting a vulnerability or voice misuse

Email **support@recapvox.com** with:

- A clear description of the issue
- Steps to reproduce (for security bugs)
- For voice/likeness misuse: evidence of ownership and links or account details

We take unauthorized voice cloning reports seriously. See https://recapvox.com/safety

Please do **not** open public issues that include private account data or exploit details.
